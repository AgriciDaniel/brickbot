# The One Principle

**If it wouldn't exist on a 1999 Nokia, it doesn't belong on this phone.**

This project is a voice call with Claude, shaped like a Nokia 3210. Every
feature must pass through the phone metaphor:

- You talk to it, it talks back. Voice first, text is only the log.
- Green key picks up the call. Green key ends it. That is the whole manual.
- The screen is a 84x48-spirit monochrome LCD: pixel art, one font, no color.
- Buttons click, the mouth moves when it speaks, the signal bars tell the
  truth about the bridge.
- No modern UI leaking in: no panels, no toasts, no mouse-first controls.
  Menus, settings, and Snake live where Nokia put them: behind the keys.
- If a feature needs explaining, it gets simplified or cut.

When in doubt: what would the phone do?
